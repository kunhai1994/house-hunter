## Example 1：按区找房（基础 search）<a id="example-1"></a>

**用户输入**：
```
/house-hunter 龙岗区 5000 以内，2房一厅或1房一厅，附近有商场，每个小区写清建成年份
```

**Opus 识别意图**：`search`（具体区 + 户型 + 预算）

**流程**：
1. 解析需求 → requirement.json
2. Python 引擎候选生成（贝壳/链家/anjuke 顺序）
3. 7 步多源 chain enrichment（每个候选）
4. **Step 2.5 WebSearch 兜底**（建成年份必填）
5. 综合评分 → Top 5
6. 按 rank.md 模板渲染

**输出结构**：
```
# 🏠 深圳市龙岗区租房报告 — 2026-05-XX
## 你的需求
## 候选小区评分（Top 5）  ← 综合分表
## 🥇 Top 1-5（详细分析）
  - 建成年份 ★（必填）
  - 物业公司
  - 配套（购物中心 / 地铁）
  - 居住口碑
  - ⚠️ 安全
## 📋 数据来源
```

**预期耗时**：2-5 分钟（含 bridge 抓取）

## Example 2：中心点搜索（search + area）<a id="example-2"></a>

**用户输入**：
```
/house-hunter 龙岗中心城为中心点，半径 1km 内找 2 房 1 厅，预算 5000，有商场
```

**Opus 识别意图**：`search` + `area="龙岗中心城"` + `search_radius_m=1000`

**特点**：
- area 字段触发**百度地图 nearby**（不走链家 /xiaoqu/{district}/ 列表）
- 半径默认 1000m（不再 5km）
- 跳过区过滤（半径内必在该区）

**输出**：
```
# 🏠 深圳市龙岗区龙岗中心城租房报告

## 候选小区（Top 5，距中心点 < 1km）
1. 万象天成（距 200m）建成 2009 物业:大众
2. 雅豪祥苑（距 350m）建成 2003 物业:德美
3. 盛龙花园（距 480m）建成 1991 物业:大众
...
```

## Example 3：多地段合并调研（research）<a id="example-3"></a>

**用户输入**：
```
/house-hunter 调研下 光明凤凰城 + 光明大街 这两个地段，最宜居的小区 Top 5
```

**Opus 识别意图**：`research`，两个 area 串行跑 + 合并

**流程**：
1. 跑两次 area 模式（各 1km）拿两组候选
2. 合并去重（按小区名）
3. 对合并后的候选**统一**走 7 步多源 chain
4. 综合评分 Top 5（按"宜居度"权重）

**输出**：
```
# 🏆 光明凤凰城 + 光明大街 · 最宜居 Top 5

| # | 小区 | 建成 | 物业 | 地段 | 宜居优势 |
| 1 | 特区建发乐府广场 | 2021 | 特区建发 | 凤凰城 | 新盘 + 国资物业 |
| 2 | 龙光玖龙台 二期-南区 | 2019 | 龙光 | 凤凰城 | ... |
...
```

## Example 4：2 方 PK（compare）<a id="example-4"></a>

**用户输入**：
```
/house-hunter 帮我调研对比 光明 电建地产洺悦府 和 中海寰宇时代花园
```

**Opus 识别意图**：`compare`（含 2 个具体小区名 + "对比"）

**关键**：**跳过 Python 候选生成**！直接对两个名字跑 7 步 chain。

**输出结构**（compare.md 模板）：
```
# 🥊 光明 电建洺悦府 vs 中海寰宇时代花园

## 基础数据对比表（建成/物业/户数/价格）
## 配套（百度地图实测距离）
## 🚨 红旗扫描
  - 电建洺悦府: 同品牌兄弟盘"鹏著"有维权舆情
  - 中海寰宇: 无明显负面
## 综合 PK
## 🏆 综合建议：中海寰宇时代花园
## 看房 checklist
## Sources（含 10+ 链接）
```

**预期耗时**：3-5 分钟（无候选生成阶段，快很多）

## Example 5：3 方 PK + 多源整合（compare）<a id="example-5"></a>

**用户输入**：
```
/house-hunter 对比下南沙越秀滨海御城、越秀滨海悦城、星河东悦湾，从口碑、配套、物业等维度
```

**Opus 识别意图**：`compare`（3 个具体小区）

**多源交叉验证**（这是 PK 的精华）：

```
对每个候选 chain：
  ① 百度地图 POI（距离）
  ② WebFetch 乐有家详情（户数/容积率/物业费）
  ③ WebSearch 黑猫投诉 + 住建局通报
  ④ WebSearch 知乎评测
  ⑤ WebSearch 二手价走势 + 急售信号
  ⑥ xhs 多关键词（口碑/避雷/噪音/漏水）
  ⑦ 区分同名（百度百科）
```

**红旗叠加表**（report 关键章节）：

| 红旗类型 | 御城 | 悦城 | 星河东悦湾 |
|---------|:----:|:----:|:--------:|
| 政府投诉 | △ | △ | 🔴 黑猫多条 |
| 二手跌价 | △ | — | 🔴 跌 50% |
| 装修吐槽 | — | — | 🔴 ❤️18/💬42 |
| 业主急售 | ⚠️ | — | ⚠️ |
| 同物业兄弟盘投诉 | △ | △ | — |
| 噪音 | — | ⚠️ 地铁 | ⚠️ 主干道 |
| 产权剩余年限 | ✅ | ⚠️ 68% | ✅ |
| 城中村紧邻 | — | — | 🔴（东侧） |

→ 综合排序：悦城 > 御城 >> 星河东悦湾

## Example 6：增量加候选（add_candidate）<a id="example-6"></a>

**用户输入**（承接 Example 5 上下文）：
```
/house-hunter 周边还有一个 南沙灵山岛金茂湾，也加进来评估
```

**Opus 识别意图**：`add_candidate`（"加" + 上文有现有 PK）

**关键**：**只对新候选跑 7 步**，不重跑前 3 个（cache 命中）

**输出**：
```
# 🥊 4 方 PK 更新 — 加入灵山岛金茂湾

## 新候选基础数据（灵山岛金茂湾）
开发商: 中国金茂 × 越秀 | 物业: 金茂物业（央企 Tier 1）
单价: 4 万/㎡（最高）
地段: 明珠湾起步区（高端规划，离金洲 5-8 km）

## 综合 PK（4 方）
[完整对比表，灵山岛单独一列]

## 🏆 新排序
🥇 悦城（金洲核心生活圈，万达对面）
🥈 灵山岛金茂湾（高端豪宅体验，但配套未起）
🥉 御城
🚫 星河东悦湾
```

## Example 7：短租 1 年重排（reweight）<a id="example-7"></a>

**用户输入**（承接前文 PK）：
```
/house-hunter 我只是短期租一年，重新评估
```

**Opus 识别意图**：`reweight`（"短期租" + 承接上文）

**关键**：**不重跑数据**，只换权重表重新算分。

**权重切换**：
```
原默认权重（长租自住）:
  价格 0.15 / 通勤 0.15 / 物业 0.15 / 配套 0.15 / 噪音 0.10 / 安全 0.10 / 户型 0.10 / 学校 0.10

新权重（短租 1 年）:
  价格 0.20 / 通勤 0.20 / 物业 0.20 / 配套 0.20 / 噪音 0.15 / 安全 0.05 / 户型 0 / 学校 0
```

**输出**（reweight.md 模板）：
```
# 🔄 短租 1 年重排

## 权重变化说明
- 价格 0.15 → 0.20（短租预算敏感）
- 学校 0.10 → 0（不需要）
- 户型 0.10 → 0（短期不在意）
- 安全 0.10 → 0.05（短期影响小）
- ...

## 排序变化
| # | 旧排序 | 新排序 | 变化原因 |
| 1 | 悦城 | 星河东悦湾 | 同价多 1 房 → 性价比 |
| 2 | 灵山岛金茂湾 | 悦城 | 万达便利仍领先 |
| 3 | 御城 | 御城 | 不变 |
| 4 | 星河东悦湾 | 灵山岛金茂湾 | 高端价格不再加分 |
```

## Example 8：不考虑价格重排（reweight）<a id="example-8"></a>

**用户输入**：
```
/house-hunter 如果不考虑价格呢
```

**Opus 自动调整**：`价格权重 → 0`，剩余权重按比例归一。

**权重重新分配**：
```
短租 1 年（带价格） → 短租 1 年（不带价格）:
  价格 0.20 → 0
  其他维度等比例提高（× 1.25）
```

**输出**：
```
# 🔄 重新排序 — 去掉价格因素

## 排序变化（去价格后）
- 星河东悦湾从第 1 跌到第 3（价格优势消失，红旗暴露）
- 悦城回到第 1（万达便利 + 业主自住 + 公园多）
- 灵山岛金茂湾上升到第 2（豪华物业现在能比）
```

**输出**：
```
# 🔄 开车场景重排

## 车位数据（新加维度）
| | 御城 | 悦城 | 东悦湾 | 灵山岛金茂湾 |

## 新排序

悦城（万达 + 公园 + 业主自住）仍第 1
```

## Example 10：栋号深挖 + 噪音原因（deepdive + why_question）<a id="example-10"></a>

**用户输入**：
```
/house-hunter 星河东悦湾 9/10/11 栋为什么噪音大？
```

**Opus 识别意图**：`why_question` + `deepdive`（栋号级）

**深度调研**（针对 9/10/11 栋）：
```
① 百度地图实测 9/10/11 栋周边道路
   → 凤凰大道 S257 距 206m / 地铁高架延伸过来 / 市南大道
② WebSearch "星河东悦湾 9 10 11 栋 噪音 西侧"
   → 拿到网易测评文章引用"9/10/11 栋西侧临主干道"
③ WebFetch 网易测评文章
   → 提取完整段落：精准证据
④ xhs 搜"星河东悦湾 9 栋""星河东悦湾 11 栋""西侧"
⑤ 用户地图截图 → Opus 视觉理解栋号方位
```

**输出结构**：
```
# 🔊 9/10/11 栋噪音 — 3 大源叠加

## 1. 地理位置（百度地图实测）
- 凤凰大道 S257 距 206m
- 地铁 4 号线高架延伸
- 市南大道（快速化改造中）

## 2. 噪音类型分析
- 源 1: 凤凰大道 24/7 车流
- 源 2: 地铁高架轨道振动（5:30-23:30）
- 源 3: 西侧旧改施工噪音（持续 1-5 年）

## 3. 网易测评精准引用
"9/10/11 栋：缺点：西侧临主干道，噪音显著；低楼层采光差"

## 4. 用户视角栋号方位图
[基于地图截图的 ASCII 示意图]

## 5. 如何规避
- ✅ 东侧 1-6 栋（蕉门河景）
- ✅ 7-8 栋（内圈，9/10/11 栋帮挡）
- ⚠️ 9/10/11 栋 5 层以下最严重
```

## 💡 进阶用法 Tips

### Tip 1：多约束串联
```
/house-hunter 短租 + 开车 + 不要地铁 + 不考虑价格 + 必须有公园
```
Opus 会逐项调整权重 + 加 must_have_pois。

### Tip 2：场景预设组合
保存常用 requirement.json 到 `~/.config/house-hunter/profiles/`：
- `young_renter.json`（25-35 岁年轻租客）
- `family_with_kid.json`（带孩子家庭）
- `investor.json`（投资视角）

### Tip 3：对话续问
跑完 PK 后直接续问 "为什么 X" / "X 的物业怎么样" — Opus 会**复用上下文**而不重新跑全部数据。

### Tip 4：导出多格式
报告默认 markdown。要 PDF？让 Opus：
```
/house-hunter 把上面的报告导出 PDF 给我
```
Opus 会调 `pandoc` 或类似工具转换。
